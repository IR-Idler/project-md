Mac build

The same file, as text and as a board. Change either one — the other follows.

Just Markdown files

Headings are lists, sub-headings are cards. Readable in any editor, no database, no lock-in.

On any device

Mac today, iPhone and iPad next. Sync the files however you like; changes show up live.

Made for a team of one

No sign-ups, invites or dashboards. Open a board, plan your week, get to work.

Opening it the first time on a Mac
  1. Open the downloaded .dmg and drag Project MD into Applications.
  2. The app isn't notarized by Apple yet, so macOS may block it. Open System Settings → Privacy & Security and click Open Anyway.
  3. If macOS says the app is damaged, run xattr -dr com.apple.quarantine "/Applications/Project MD.app" in Terminal once.
